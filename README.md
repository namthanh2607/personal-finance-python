# Personal Finance Tracker (Python)

Ứng dụng quản lý chi tiêu cá nhân được viết bằng Python.

## Tính năng chính
- Xem danh sách các khoản chi tiêu.
- Thêm khoản chi tiêu mới kèm số tiền.
- Tự động tính tổng số tiền đã tiêu.
- **Lưu dữ liệu tự động:** Dữ liệu được lưu vào file `chi_tieu.json`, không lo mất dữ liệu khi tắt app.

## Công nghệ sử dụng
- **Ngôn ngữ:** Python 3
- **Thư viện:** `json`, `os` (có sẵn trong Python)

## Cách chạy chương trình
1. Đảm bảo máy tính đã cài Python.
2. Mở Terminal tại thư mục dự án và gõ:
   ```bash
   python main.py
